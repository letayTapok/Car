# Игра «Car» — аркадная погоня на PyGame

## Легенда

Игрок управляет красной машиной в бесконечно генерируемом городе. Цель — собирать золотые монеты на дорогах, копить очки и как можно дольше уходить от преследования: полиция спавнится рядом с игроком и целенаправленно движется к нему. Столкновение с полицией или любым препятствием (домом, деревом) приводит к взрыву и концу игры.

## Возможности

- управление машиной с реалистичной физикой: разгон, торможение, задний ход, инерция и повороты на скорости
- процедурная генерация города: мир разделён на ячейки, при движении игрока подгружаются соседние ячейки с домами, деревьями, дорогами с разметкой и парковками
- бесшовно следящая камера с плавным сглаживанием
- сбор монет с анимацией пульсации; удаление монет, до которых игрок не доехал
- система буста: за 10 накопленных монет доступно ускорение на 5 секунд (+10% к максимальной скорости), с обратным отсчётом на экране
- ИИ преследователей: патрульные машины и фургон вычисляют угол до игрока и корректируют курс, мигающие красно-синие огни
- проверка столкновений по попиксельным маскам, а не по прямоугольникам
- эффект взрыва: система из 180 частиц и расширяющаяся ударная волна
- подсчёт очков и рекорда сессии, рестарт игры после аварии

## Управление

| Клавиша | Действие |
| --- | --- |
| `W` / `↑` | газ |
| `S` / `↓` | тормоз и задний ход |
| `A` / `←`, `D` / `→` | поворот руля |
| `T` | активировать ускорение за 10 монет |
| `R` | перезапуск после аварии |

## Используемые технологии

- Python 3.x
- Pygame

## Ключевые классы

- `Camera` — плавная камера и перевод мировых координат в экранные
- `CityGrid` — генерация города: дороги, парковки, дома, деревья, монеты по ячейкам
- `Coin` — монета с анимацией и маской коллизий
- `Particle`, `Explosion` — система частиц и взрыва с ударной волной
- `StaticObstacle` → `DetailedTree`, `DetailedHouse` — препятствия с процедурной отрисовкой
- `Vehicle` → `Player`, `PoliceCar`, `PoliceVan` — базовый класс транспорта с физикой и наследники с разным поведением

## Запуск

Установите зависимости:

```
pip install pygame
```

Из корня проекта выполните команду:

```
python main.py
```

После запуска откроется окно игры 1000×700. Игра начинается в центре города — собирайте монеты на дорогах и не подпускайте полицию!
